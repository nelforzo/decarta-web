    Why do I have to pick the file?

    Browsers refuse fetch() from a file:// page, so the viewer cannot read resources/corpus.db on its own the way it can when the page is served over http. Two ways out:

    • drop or pick resources/corpus.db above — it is read locally, nothing is uploaded anywhere; or
    • start the browser with file access enabled, scripts/open-viewer.command, which makes resources/ load automatically in Chrome, Edge or Brave.

    The pictures are always read straight from resources/media/, so media shows up either way.
